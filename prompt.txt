在现有 terrain 骨架上，把它做成一个可复现、可平铺的分形地形生成器。保留 value_noise_1d、fbm、
generate、normalize、save_png 的现有名字与签名，只用 Python 标准库，不得引入第三方依赖，
不得改动 data/specs.json。

## 需要完成

1. **可复现**
   - 同一 seed 连续跑两次，输出 PNG 逐字节相同。
   - 不同 seed 的输出要有明显差异，差异判据写进 README。

2. **各向同性**
   - 水平与垂直方向的频率一致，图里不能出现单一方向的斜条纹。

3. **层叠加**
   - 各层振幅归一，`octaves` 从 3 到 7 变化时，整体亮度和对比度保持稳定。
   - 高频层不能盖过低频层的地貌骨架。

4. **可平铺**
   - 左右边缘与上下边缘拼接后不能有接缝，判据写进测试。

5. **水位**
   - `specs.json` 里的水位要真正生效，输出水体掩码并在报告里给出水域占比。
   - 水位为 0 的地貌不能出现水体。

6. **测试**
   - 覆盖：同 seed 一致、不同 seed 有差异、层数变化亮度稳定、边缘接缝、水位掩码。
   - `python -m pytest tests -q` 全部通过。

完成后按 `specs.json` 依次生成三张地形，把每张的高度范围、水域占比、左右边缘拼接的最大高差
贴进 README。
